# 语音文件缓存目录

本目录用于存放 `edge-tts` 实时合成的语音文件（`audio_*.mp3`）。

## 说明

- 📌 **本目录内容不入库**：`.mp3` 文件已在 `.gitignore` 中排除
- 🔧 **无需手动创建**：程序启动时（`main.py`）会自动创建本目录
- 🌐 **访问路径**：生成的语音通过 `/static/audio/audio_<id>.mp3` 对外提供
- 🧹 **清理策略**：语音文件为一次性缓存，可定期清理，不影响系统运行

## 快速验证

启动后端后访问 `http://localhost:8000/app`，发送任意消息，本目录下会自动出现 `audio_*.mp3` 文件。
